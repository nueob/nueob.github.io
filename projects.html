Node.jsTypeScriptExpressMySQLRedisFCMClaude Code

주요 역할 · 구현

  • 단순 구현에 그치지 않고 기능·구조 개선을 적극 제안하며 서비스를 주도적으로 설계·구현했습니다.
  • AI(Claude Code)를 활용해 iOS·Android 네이티브 앱을 개발하고 안정적으로 배포 (직접 네이티브 코딩이 아닌 AI 활용 개발 방식).
  • Claude Code(AI)를 적극 활용해 반복 작업을 자동화하고 개발 시간을 약 1/4로 단축.
  • 기획자가 간단한 퍼블리싱(마크업·문구 수정 등)을 직접 처리할 수 있도록 개발 환경 세팅을 지원해 협업 효율을 높임.

성과

  • 신규 커뮤니티 도메인을 백엔드부터 웹 프론트까지 풀스택으로, AI를 활용한 iOS·Android 네이티브 앱 개발까지 단독에 가깝게 책임지고 출시.

운영 정책 위반 자동 탐지 (AI 파이프라인)

Amazon Bedrock LLM 기반으로 사용자 게시글의 운영 정책 위반을 자동 판별·점수화하는 파이프라인. (비누커리어 · 캠퍼스픽)

AWS Bedrock (Claude)AWS LambdaNode.jsTypeScriptPrompt Engineering

배경 · 문제

  • 커뮤니티에 게시되는 글의 운영 정책 위반 여부를 운영팀이 수동으로 검수하고 있어, 자동화로 운영 부담을 줄일 필요가 있었습니다.

주요 역할 · 구현

  • Amazon Bedrock LLM(Claude) 기반으로 게시글의 정책 위반 여부를 판별하고 점수화하는 파이프라인을 설계·구현.
  • Prompt Engineering과 텍스트 전처리 로직을 설계하고 AWS Lambda 기반으로 운영.

성과

  • 위반 탐지 정확도 90%+ 달성, 운영팀의 수동 검수 업무를 자동화하여 운영 공수 절감.

SSO · 외부 API 연동

인증(SSO)과 외부 파트너 API 연동을 풀스택으로 구현. (유니브스토어 · 비누커머스)

Node.jsTypeScriptOAuth삼성 SDS APIJest / MSW

주요 역할 · 구현

  • 에브리타임 OAuth/SSO 로그인·자동가입 통합 구축외부 플랫폼 OAuth, 본인인증(CI) 중복체크, 약관·탈퇴 연동까지 인증 전 과정 신규 설계.
  • 삼성 SDS 트레이드인(중고폰 보상) 외부 API 연동모델/단가 조회·신청·상태조회 API 설계, 외부 응답 매핑, 장바구니·결제 플로우 분기, 단위·통합 테스트(Jest/MSW).

성과

  • 인증·외부 연동의 신뢰도와 테스트 가능성을 확보하고, 연동 장애 대응력을 강화.
