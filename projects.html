갓생피드 — 인증형 SNS

백엔드 설계·구현부터 웹 배포까지 담당한 신규 커뮤니티 서비스. (비누커리어 · 캠퍼스픽)

Node.jsTypeScriptExpressMySQLRedisSocket.IOFCMVue 2.7Claude Code

배경 · 문제

  • 사용자의 '갓생'(자기계발 인증) 활동을 공유하는 신규 커뮤니티가 필요했고, 단순 게시 피드를 넘어 지속적인 참여 유도와 어뷰징에 강한 노출 구조가 요구되었습니다.

주요 역할 · 구현

  • 단순 구현에 그치지 않고 기능·구조 개선을 적극 제안하며 백엔드를 주도적으로 설계·구현했습니다.
  • 인기글 노출 방식을 직접 제안·설계 — 레딧식 hot-score 랭킹 알고리즘(좋아요·댓글·첨부 가중 로그 점수 + 48시간 윈도우 + 유저당 노출 제한·신고 임계값 필터링)으로 어뷰징에 강한 피드를 구성.
  • 게시/댓글/대댓글·좋아요·신고 등 피드 도메인 백엔드를 신규 설계·구현 (단일 API 모듈 약 1,770줄).
  • 스트릭(연속 인증), 좋아요·댓글 마일스톤 FCM 푸시 등 참여 유도 기능 구현.
  • 작성자와의 1:1 채팅(Socket.IO) 연동, 웹(Vue 2.7 SSR) 풀스택 구현 후 배포.
  • Claude Code(AI)를 적극 활용해 반복 작업을 자동화하고 개발 시간을 약 1/4로 단축.
  • 기획자가 간단한 퍼블리싱(마크업·문구 수정 등)을 직접 처리할 수 있도록 개발 환경 세팅을 지원해 협업 효율을 높임.

성과

  • 신규 커뮤니티 도메인을 백엔드 설계·구현부터 웹 배포까지 단독에 가깝게 책임지고 출시.

* iOS·Android 앱은 일부 기능 구현을 직접 경험했습니다.

파트너 정산 시스템 자동화

수작업 중심의 정산 업무를 전 주기 자동화한 백엔드 시스템 (주 개발자). (유니브스토어)

Node.jsTypeScriptExpressMySQLAWS S3

배경 · 문제

  • 정산을 시스템이 아닌 사람이 수기로 처리하는 경우가 많았고, 커머스 규모가 커질 경우를 대비한 확장성이 필요했습니다.
  • 자회사에서 본사로 자동 전자 결재가 이루어지지 않아 운영상의 불편이 있었습니다.

주요 역할 · 구현

  • 정산 명세서 생성 → 검증 → 승인 → 세금계산서 발행 → 파트너 메일 통보까지 전 주기를 자동화.
  • 본사 API 연동을 통한 자동 전자 결재 생성 기능 추가.
  • 정산일 산정·추가매출·0원 정산 등 복잡한 도메인 규칙 처리, 엑셀/PDF 리포팅.
  • 정산 캐시 도입 및 쿼리 최적화로 조회 성능 개선.

성과

  • 수작업 중심 정산 업무를 자동화하여 운영 공수를 크게 절감.

SSO · 결제 · 외부 API 연동

인증 · 결제 · 외부 연동 전 과정을 풀스택으로 구현. (유니브스토어 · 비누커머스)

Node.jsTypeScriptOAuth이니시스 / 카카오페이삼성 SDS APIJest / MSW

주요 역할 · 구현

  • 에브리타임 OAuth/SSO 로그인·자동가입 통합 구축 — 외부 플랫폼 OAuth, 웹뷰 자동로그인, 본인인증(CI) 중복체크, 약관·탈퇴 연동까지 인증 전 과정 신규 설계.
  • PG 결제 모듈 추상화 — 이니시스·카카오페이를 PaymentService 추상화로 분리하고 단위·통합 테스트(Jest/MSW) 동반. 망취소·tid 누락 등 결제 엣지케이스 대응.
  • 삼성 SDS 트레이드인(중고폰 보상) 외부 API 연동 — 모델/단가 조회·신청·상태조회 API 설계, 외부 응답 매핑, 장바구니·결제 플로우 분기 (TLS 호환 이슈 직접 해결).

성과

  • 인증·결제·외부 연동의 신뢰도와 테스트 가능성을 확보하고, 결제 장애 대응력을 강화.

고가용성 서버리스 API

메인 서버와 트래픽·장애를 격리한 독립 서버리스 API와 비동기 워커 시스템. (비누커머스 · 비누커리어)

AWS LambdaAPI GatewaySQSCloudWatchNode.jsTypeScript

배경 · 문제

  • 에브리타임 앱에 캠퍼스픽 콘텐츠(홈·인기글·스터디 등)를 노출하는 연동이 필요했고, 에브리타임의 대규모 트래픽과 메인 서버 장애가 서로 영향을 주지 않도록 메인 백엔드와 분리된 독립 API가 요구되었습니다.

주요 역할 · 구현

  • API Gateway + Lambda 기반 서버리스 아키텍처를 신규 설계·구현 (메인 서버 의존 없는 고가용성).
  • 모든 요청을 CloudWatch로 100% 로깅·모니터링하고 Alarm으로 오류 알림 체계 구축.
  • SQS 비동기 워커 시스템 설계 — 40+ 액션 핸들러(삭제 cascade·푸시·메일·배치)와 공통 모듈로 타입·메시지 계약을 표준화.

성과

  • 메인 서버와 독립적으로 동작하는 고가용성 연동 API 구축, 트래픽·장애 격리로 서비스 안정성·관찰성 강화.

단상(Dansang) — AI 커뮤니케이션 코치

발표·면접 불안을 겪는 학생을 위한 AI 훈련 서비스 (발표·토론·질문 3개 모드). 전사 개발자·기획자가 참여한 사내 AI 해커톤 출품작 — 개발자 3인 팀의 백엔드 담당.

ExpressAWS Bedrock (Claude 3.5)TranscribePollyS3Claude Code

배경

  • 회사의 전 개발자·기획자가 참여한 사내 AI 해커톤으로, 모든 팀이 Claude Code(AI)를 활용해 개발하는 방식으로 진행되었습니다.

주요 역할 · 구현

  • Express API + AWS Bedrock(Claude 3.5)·Transcribe(STT)·Polly(TTS)·S3 연동으로 음성 분석·피드백·AI 페르소나 대화 엔진을 구현.
  • 개발자 3인이 일관되고 효율적으로 AI 협업을 하도록 팀 공용 CLAUDE.md(프로젝트 규칙·컨벤션 가이드)를 직접 작성·공유 — 팀 전체의 AI 개발 생산성을 끌어올렸습니다.
  • 아키텍처 문서를 선(先)정의해 협업 토큰 사용량 70% 절감.

성과

  • 3일 만에 MVP 완성, 베타 테스터 50명 평균 발표 점수 35% 향상.
  • 전사 개발자·기획자가 참여한 사내 AI 해커톤에서 우수상(2등) 수상.
